# AR Building Blueprint Visualizer

An Android augmented reality app (Unity 6, C#) that turns a 2D building blueprint into an interactive 3D model placed on a real surface.

> Construction professionals and clients often find it difficult to interpret 2D architectural blueprints. This project develops an AR Blueprint Visualizer that converts building plans into interactive 3D models for better understanding, planning, and design validation.

## What it does

- Scans the surroundings with ARCore and shows detected horizontal surfaces as a blue grid.
- Places a building on the surface with one tap.
- Shows each floor first as a **2D blueprint** (room names, room areas, doors, windows, scale 1:5), then **converts it to 3D** so the walls rise from the plan.
- Three default floors (living area, bedrooms, rooftop terrace), viewable one at a time or stacked.
- **Floor Creator:** design 1 to 3 floors with a chosen layout, 1 to 4 rooms, flooring, wall colour, and furniture on or off.
- Drag, twist, and pinch gestures to move, rotate, and scale the building.
- Textured materials, reflective glass, soft shadows, and ARCore light estimation.

The 2D blueprint and the 3D model are generated from the same plan data, so they always match. Everything runs on the phone: no server or cloud.

## Requirements

- Unity 6 (6000.6.0f1) with Android Build Support
- AR Foundation 6.6.2, ARCore XR Plugin 6.6.2, Universal Render Pipeline 17.6.0, Input System 1.20.0 (installed through the Package Manager)
- An ARCore-supported Android phone (Android 8.0 / API 26 or later, ARM64)

## Getting started

1. Open this folder in Unity Hub with Unity 6000.6.0f1.
2. Open `Assets/_Project/Scenes/ARBuildingVisualizer.unity`.
3. To regenerate the materials, textures, prefab, scene, and UI, use the menu **AR Blueprint > Build Complete Project**.
4. To build the app, use **AR Blueprint > Build Android APK** (the APK is written to `Builds/`), or build from File > Build Settings for Android.
5. Install the APK on an ARCore phone, allow camera access, move the phone slowly over a floor or table, and tap the blue grid.

AR cannot run in the Unity editor's Play mode; test on a phone.

## Controls

| Control | Action |
|---|---|
| Tap the blue grid | Place the building |
| FLOOR 1 / 2 / 3 | Show one floor |
| STACKED | Show all floors stacked |
| 2D BLUEPRINT / CONVERT TO 3D | Switch between the blueprint and the 3D model |
| CREATE FLOORS | Open the Floor Creator |
| DEFAULT PLANS | Restore the three default floors |
| RESET | Remove the building and place it again |
| Drag / twist / pinch | Move / rotate / scale the building |

## Project structure

```
Assets/_Project/
  Scripts/      Runtime C# scripts (placement, floors, blueprint, UI, light estimation)
  Editor/       Editor tools that generate materials, textures, the scene, and build the APK
  Resources/    Generated materials loaded at run time
  Textures/     Generated seamless textures and normal maps
  Prefabs/      Building root and AR plane visual
  Scenes/       ARBuildingVisualizer scene
```

All textures are generated by script and the building is made from simple boxes, so the project uses no downloaded art assets.
